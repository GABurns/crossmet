# Import weather data from Excel

An internal plotting for consistency.

## Usage

``` r
plot_weather_variable(
  data,
  variable,
  title,
  ylab,
  caption = "Location: Crossnacreevy, Northern Ireland",
  colour = "#2C7FB8",
  geom = "line"
)
```

## Arguments

- data:

  A data.frame

## Value

A ggplot2 object.
