# crossmet

This package provides tools for processing, summarising and visualising
daily meteorological data from the AFBI Crossnacreevy weather station.

It transforms daily weather summaries into monthly summary tables and a
range of data visualisations, making it easier to explore seasonal
patterns, monitor weather conditions and examine historical
meteorological trends.

The package is designed to provide a consistent and reproducible
workflow for summarising weather observations, with outputs suitable for
reporting, exploratory data analysis and further research.

## Installation

You can install the development version of crossmet from
[GitHub](https://github.com/) with:

``` r

# install.packages("pak")
pak::pak("GABurns/crossmet")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r

library(crossmet)
## basic example code
```
